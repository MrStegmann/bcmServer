# Implementation Plan: Setup BCMServer Project

**Branch**: `001-setup-bcmserver-project` | **Date**: 2026-10-29 | **Spec**: [specs/001-setup-bcmserver-project/spec.md](file:///j:/GitHub/BasketApp/bcmServer/specs/001-setup-bcmserver-project/spec.md)

**Input**: Feature specification from `/specs/001-setup-bcmserver-project/spec.md`

## Summary

Bootstrap the foundation of the `bcmServer` backend application using Java 21, Spring Boot 3.4.x, and Maven. Establish a strictly separated Hexagonal Architecture skeleton, configure HikariCP connection pooling to connect to PostgreSQL with externalized environment variables (`.env.example`), enforce passive schema mode (`ddl-auto: none`), provide a `docker-compose.yml` for local database orchestration, and verify reliable cold-start database connectivity and fail-fast behavior.

## Technical Context

**Language/Version**: Java 21 LTS (OpenJDK 21)  
**Primary Dependencies**:
- `spring-boot-starter-web` (Spring Boot 3.4.x)
- `spring-boot-starter-data-jpa`
- `spring-boot-starter-actuator`
- `org.postgresql:postgresql` (PostgreSQL JDBC driver)
- `spring-boot-starter-validation`
- `springdoc-openapi-starter-webmvc-ui` (OpenAPI 3 / Swagger documentation baseline)

**Storage**: PostgreSQL 16 (via HikariCP connection pool; `ddl-auto: none`)  
**Testing**: JUnit 5, Mockito, Spring Boot Test Starter (`@SpringBootTest`, `@WebMvcTest`, `@DataJpaTest`)  
**Target Platform**: Multi-platform JVM (Linux server, macOS, Windows, Docker container)  
**Project Type**: Spring Boot Web Service / REST API application  
**Performance Goals**:
- Cold startup and database connection verification in < 15 seconds (SC-002)
- Fail-fast database connectivity timeout in < 10 seconds (SC-004)

**Constraints**:
- 100% credential externalization via environment variables (`.env.example`)
- Passive DDL mode (`ddl-auto: none`) to prevent destructive schema changes
- Hexagonal Architecture layout isolating domain, application, and infrastructure layers

**Scale/Scope**: Architectural baseline and runtime verification for the Basket Club Manager (BCM) server.
